# فاست غاز — Fast Gaz

موقع ورشة **فاست غاز** لتركيب وصيانة السيرغاز، مع نظام كامل لحجز مواعيد التركيب ولوحة إدارة.

## المميزات

**للزبائن:**
- صفحة رئيسية بالعربية (من اليمين لليسار) تعمل على الهاتف والكمبيوتر
- عرض الخدمات، لماذا نحن، خطوات الحجز، أسئلة شائعة، ومعلومات الاتصال
- حجز موعد: اختيار الخدمة ← اليوم ← الوقت المتاح ← معلومات السيارة والزبون
- الأوقات المحجوزة بالكامل تظهر "محجوز" تلقائياً، وأيام العطل مغلقة
- رقم حجز (مثل `FG-7KQ2MX`) وزر لإرسال تأكيد الحجز عبر واتساب
- تتبع حالة الحجز أو إلغاؤه برقم الحجز + رقم الهاتف
- زر واتساب عائم

**لصاحب الورشة (`/admin`):**
- إحصائيات: مواعيد اليوم، في انتظار التأكيد، المؤكدة، المنجزة
- عرض المواعيد مجمعة حسب اليوم، مع فلاتر (اليوم، غداً، 7 أيام، بحث...)
- تغيير الحالة: في انتظار التأكيد / مؤكد / منجز / ملغى
- زر واتساب يرسل رسالة تأكيد جاهزة للزبون، وزر اتصال مباشر
- طباعة قائمة مواعيد اليوم

## التشغيل

يتطلب **Node.js 22.13 أو أحدث** فقط — لا توجد أي مكتبات إضافية (قاعدة البيانات SQLite مدمجة في Node).

```bash
ADMIN_PASSWORD=كلمة_سر_قوية npm start
```

ثم افتح:
- الموقع: http://localhost:3000
- لوحة الإدارة: http://localhost:3000/admin

### المتغيرات

| المتغير | الوصف | الافتراضي |
|---|---|---|
| `ADMIN_PASSWORD` | كلمة مرور لوحة الإدارة (**غيّرها!**) | `admin123` |
| `PORT` | المنفذ | `3000` |
| `DATA_DIR` | مجلد قاعدة البيانات | `./data` |
| `SESSION_SECRET` | مفتاح الجلسات (ثابت حتى لا تخرج من اللوحة عند إعادة التشغيل) | عشوائي |
| `TRUST_PROXY` | ضعها `1` إذا كان الموقع خلف Nginx/Cloudflare | — |

## التخصيص

كل معلومات الورشة في ملف **`config.js`**:
- الاسم، رقم الهاتف، رقم الواتساب، العنوان، رابط الخريطة
- أيام العمل وأوقات المواعيد (`slots`)
- عدد السيارات في نفس الموعد (`capacityPerSlot`)
- أيام العطل الاستثنائية (`holidays`)
- الخدمات ومدتها وأسعارها

بعد التعديل أعد تشغيل الخادم.

## النشر على الإنترنت

يمكن نشره على أي استضافة تدعم Node.js (مثل Render أو Railway أو VPS):
1. أمر التشغيل: `npm start`
2. أضف المتغير `ADMIN_PASSWORD`
3. اجعل `DATA_DIR` على قرص دائم (Persistent Disk) حتى لا تضيع الحجوزات
4. احتفظ بنسخة احتياطية من الملف `data/fastgaz.db`
